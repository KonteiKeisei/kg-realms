# KG Realms user guide

Review draft. KG Realms 0.93.13, including first-load integration setup. Installation uses supplied screenshots. Other screenshots will be added in reading order.

Trorune is the example world used in this guide.

## Start here

GM: install the engine, set up a realm, then prepare the party. Complete these steps before starting travel.

Player: your GM prepares the map and party. Start with [Map controls: player](04-map-player.md), then [Your first journey](05-journey-player.md).

## Setup paths

- Companion realm: [install](01-install.md), [generate its realm scene](02-realm.md#use-a-companion-realm-module), [prepare the party](03-party.md), [start travel](05-journey-gm.md).
- Exported realm module: [install and import its prepared realm scene](02-realm.md#use-an-exported-realm-module), [prepare the party](03-party.md), [start travel](05-journey-gm.md).
- Your own map: [install](01-install.md), [convert the image](02-realm.md#use-your-own-map-image), [add places and prepare the party](03-party.md), [start travel](05-journey-gm.md).
- Detailed map beneath a realm: complete realm setup, then use [Regional maps](10-regional.md).
- Settlement or site scene: complete realm setup, then use [Local maps](11-local-gm.md).
