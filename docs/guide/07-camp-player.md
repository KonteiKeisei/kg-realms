# Camp, watches and rest: player

Audience: player. Required: an owned character in the travelling group and a camp started by the GM.


## Prepare

1. Open Travel and select Camp when it appears.
2. Choose your character's task if the Tasks step is available.
3. Check the proposed watch order and sleep allocation.
4. If shared arrangement is available, take your turn and adjust the order using the watch controls.
5. Wait for the GM to begin camp setup.

Other characters' task fields can be disabled if you do not own them. Watch arrangement can be restricted by the GM.



## Answer a roll

1. Check which character and skill the request names.
2. Click the offered roll control in the camp panel or request card.
3. Choose an offered skill if the task allows alternatives.
4. Wait for the next camp phase.

A result or DC may be hidden by the GM's settings. A missing GM encounter roll is not a request for you to roll it.

## Complete rest

The GM runs the camp through rest and packing. If a character recovery request appears, answer it for your character.

Do not start an additional ordinary long rest just to duplicate the camp's recovery request. Ask the GM if the request is missing.
