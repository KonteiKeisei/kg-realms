First journey: GM

Audience: Primary GM. Required: realm, group actor and placed party token.

Recommended: Calendaria for the calendar and time controls used during travel.

Plan a short trip

  1. Open the realm scene.
  2. Click Travel in the scene controls.
  3. Check that the panel is using the intended party.
  4. In Where to?, choose a named destination. Alternatively, click Pick on the map and click the destination.
  5. If editing on the map, click Finish route.
  6. Check the listed stops, Distance and Time.

The starting position comes from the party token. Move it before starting if it is in the wrong place.

Set the journey options

  1. Click Setup.
  2. Set Travelling by. Use On foot for a first walking trip.
  3. Choose Slow, Normal or Fast pace.
  4. Set Hours on the road and Hours in camp.
  5. Choose Players see: Route, Progress or Nothing.
  6. Click Done to close Setup.
Players seePlayer display
RouteThe shared route and journey details
ProgressJourney progress without the full itinerary
NothingTravel rules; journey details are hidden

This option controls journey display. It does not change ordinary place discovery.

Start and advance

  1. Click Start travel.
  2. Advance world time through your time controls, or use Skip to next camp in Travel.
  3. Resolve any encounter or camp decision that interrupts the journey.
  4. Continue until the status reads Arrived.

Starting travel records the departure. It does not run the clock by itself. The party moves as world time advances.

Skip to next camp advances to the next camp decision and stops at intervening encounters. Camp setup and sleep have not started merely because this button was used.

Skip to next encounter advances toward the next road encounter, accounting for nights. It is different from the interactive camp workflow.

Pause and resume

Click Pause travel to halt movement. World time can still pass. Click Resume travel when ready to continue.

Opening and activating scenes have different effects. Leaving the linked realm/Regional views for an unrelated scene can put travel into an away pause. Return to the travel map and check the status before continuing.

Finish

At Arrived:

  • Enter the destination if a linked local scene and suitable entrance are available.
  • Click New journey to clear the previous route and progress after confirmation.

More > Back to the start returns the party to its departure position. It does not rewind world time.
