Multiple parties and GM control

Audience: Primary GM. Required: placed D&D 5e group tokens.

Split a party

  1. Select the group token.
  2. Open its token HUD and click Split party.
  3. Drag members from the original party to New party.
  4. Use Shift-click or Ctrl-click to select several members before dragging them together.
  5. Click Confirm.

Character sheets and their items remain with the character actors. Pooled group inventory remains with the original group.

Merge parties

  1. Select the group tokens to combine.
  2. Open the token HUD's Merge party control.
  3. Move the members into the intended group.
  4. Review the membership on both sides.
  5. Click Confirm.

The controls validate current membership. If another GM changed the groups while the window was open, close and reopen it before trying again.

Separate journeys

Travel displays party tabs when multiple groups are present. Select the intended tab before planning, pausing or resolving its journey. Each party has its own token and travel state.

Splitting during a settlement trip stops that trip where the party is. Review the groups and begin the next trip with the intended passengers.

Scene party overrides take priority over the global Party token actor setting. Use Party setup when the wrong group is selected.

Primary GM

  1. Open Configure Settings > KG Realms.
  2. Choose Primary GM.
  3. Save the setting.

The Primary GM controls journey time, movement, shared camp actions and player requests. If the selected GM is offline, the first connected GM in the user list takes over. A secondary GM can have map-editing controls without owning journey progression.

Players need character ownership for their own task and roll controls. Shared watch arrangement is a separate camp option.
