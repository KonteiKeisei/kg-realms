Camp, watches and rest: GM

Audience: Primary GM. Required: an active journey and its group members.

Recommended: Calendaria for watch, camp and rest timekeeping.

Prepare optional camp tasks

  1. Open Configure Settings > KG Realms > Advanced watches.
  2. Enable Advanced watches, then enable the preparation tasks you want: Foraging, Concealment and Alarms.
  3. Drop an item into Ration item if successful foraging should give characters that item.
  4. Drop a RollTable into Random encounter table if camp encounters should use it.

Without a ration item, foraging shows its result without granting that item. Without a table, the module uses its fallback camp encounter.

Reach the end of a travel day

At the daily limit, choose whether to make camp or push on. Pushing on advances travel and can invoke forced-travel rules. Making camp opens camp preparation.

Arrange camp

  1. Assign or review tasks. Players can choose tasks for actors they own.
  2. Open Watches and arrange the watch order.
  3. Check the timeline for each member's watch and rest requirements.
  4. Enable Only I arrange the watch if players should not change it.
  5. Use Take over to end another user's current arrangement turn if needed.
  6. Review Camp plan, including the camp duration and encounter settings.
  7. Click Begin camp setup.

Enabled tasks add preparation checks. Follow the current step's request controls; answer for NPCs or characters without an active owner when needed.

Tasks

TaskCheck or effect
No setup workNo extra preparation task; assign watch duty separately
ForageSurvival; successful foraging grants the configured ration item
Conceal the campSurvival or Stealth; successful work affects the night's encounter dice
Set alarmsSurvival or Sleight of Hand; success improves warning for the night

Watch duty is separate from preparation work. A character who did setup work can also watch, with the applicable disadvantage on watch checks.

Use the Rules tooltips for the active rule set and exact modifiers. The actor's sleep requirement affects the plan; check unusual or renamed species/features rather than assuming detection is correct.

Run the night

  1. Resolve preparation checks.
  2. Advance using the camp's current phase controls.
  3. Resolve watch checks and any encounter.
  4. Conclude the encounter before continuing the night.
  5. Complete rest and packing.
  6. Resume the journey.

Camp setup, watches and packing advance world time. Completing a camp is different from merely advancing to the next camp decision.

Rest Recovery

With Rest Recovery enabled, completion requests character recovery for the party. Players answer those requests. The camp has already advanced time; answering a recovery request does not add the whole camp duration again.

KG Realms does not change Rest Recovery's global time-passage setting or active profile. Keep ordinary-rest settings configured for your normal non-camp rests.

Sea travel

With Watches at sea off, the crew of a crewed ship handles watches while the party sleeps. Enable it if the party should keep its watch order during voyages.

Practice

Open Map editor > Practice to rehearse the camp workflow. The practice is a demonstration; use it to check the sequence before running a journey with the group.
