# Trade: GM

Audience: GM. Required: a place card with trade support.

## Edit a market

1. Open the place's full card.
2. Open Trade.
3. Click Edit trade.
4. Select Starting profile and click Use profile defaults if using a supplied market. Otherwise choose a good or Custom good and click Add good.
5. Set each good's name, unit, role, base price, local multiplier and availability.
6. Add a supplier or description where needed.
7. Set Hide this good from players for private rows.
8. Save the editor's changes.


Supplied profiles and signature goods depend on the companion realm. A custom realm can have no supplied trade data.

## Prices

Configure Settings > KG Realms > Prices applies the world economy multiplier. The editor displays the economy-adjusted base price. The local multiplier applies on top of it.

Check the listed unit. A price for 1 lb is not a price for an entire crate unless that is the unit you entered.

Prices also affects default realm ship/coach fares and settlement coach pricing. An individually haggled realm leg fare stays as set.

## Inventory and payment

The Trade tab is a price and availability reference. It does not provide a buy/sell transaction, stock depletion or automatic item transfer. Handle those through your normal game workflow.

This differs from the settlement coach system, which handles passenger fares when starting a trip.
